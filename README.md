## 👋 About Me

I'm Suraj Navgire, a QA Engineer passionate about software quality, test automation, and identifying issues before they reach end users.

My experience includes testing web applications, mobile applications, e-commerce platforms, administrative CMS systems, and API integrations.

I combine structured manual testing with automation-focused problem-solving to improve application reliability, usability, and release confidence.

### 🎯 What I Bring to a QA Team

- **Manual Testing:** Functional, regression, smoke, sanity, exploratory, and end-to-end testing.
- **Test Automation:** Building and maintaining UI automation tests using Playwright and TypeScript.
- **API Testing:** Validating REST APIs, HTTP methods, response codes, payloads, and error handling using Postman.
- **Defect Management:** Identifying, documenting, prioritizing, retesting, and tracking defects.
- **Test Design:** Creating positive, negative, boundary-value, and data-validation scenarios.
- **Quality Ownership:** Analyzing requirements, identifying edge cases, and validating complete user workflows.
